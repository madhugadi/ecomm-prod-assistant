📌 Projects Overview
🛒 E-Commerce Product Assistant

🔗 GitHub Repository

An AI-powered e-commerce chatbot that answers natural-language product queries with high accuracy using RAG + hybrid retrieval.

🔍 Key Features
Semantic search with vector embeddings + reranking
Contextual compression to reduce token usage and hallucinations
Hybrid retrieval with DuckDuckGo web search fallback for real-time data
Modular MCP-based architecture (retrieval, ranking, compression, generation)
Scalable microservices deployed on AWS EKS
🏗️ Architecture Highlights
Containerized services orchestrated via Kubernetes
Secure access with IAM roles
Observability via CloudWatch logs and metrics
🧰 Tech Stack

Python · FastAPI · LangChain · LangGraph · MCP · RAG · Vector Embeddings · Astra DB · DuckDuckGo API · Docker · Kubernetes (EKS) · AWS IAM · CloudWatch
